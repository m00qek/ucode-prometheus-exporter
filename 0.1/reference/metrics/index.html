    Metrics¶

    The metric families each collector writes, and those a scrape writes of itself. Types, labels and help texts are what the collectors write: each collector runs as a scrape runs it, on each set of captures in test/fixtures/ (an access point, a router, a second router, made-up captures), with its defaults and with each boolean option the other way. A family that only an option writes says which.

    The labels are those seen on the captures; a collector leaves out a label it has no value for, so a device may show fewer. Families whose names hold what the source reports (a driver's statistics, a kernel table's fields) are one row, their name a pattern in <>. Families no capture shows are listed from the collector's code, and say why.

    Renamed metrics lists the names that changed from the feed's exporters.

    The scrape's own¶

    Every scrape ends with these, whatever collect[] selects: node_exporter's families of each collector that ran, and the exporter's version.

    Family Type Labels Help Notes
    node_scrape_collector_duration_seconds gauge collector node_exporter: Duration of a collector scrape. —
    node_scrape_collector_success gauge collector node_exporter: Whether a collector succeeded. —
    node_scrape_collector_observing gauge collector Whether a collector had something to observe: 0 when its hardware, kernel feature or service is not there. —
    ucode_prometheus_exporter_build_info gauge version A metric with a constant '1' value labeled by the version of ucode-prometheus-exporter. —
