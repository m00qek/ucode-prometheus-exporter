    UCI Configuration¶

    The exporter's configuration is /etc/config/prometheus-exporter, and the hash of basic auth's password is apart, in /etc/config/prometheus-exporter-auth (below). The files are optional: every option has a default, an unset option takes it, and an option the exporter does not know is ignored. Changes apply on reload_config or service prometheus-exporter reload.

    The main section¶

    config prometheus-exporter 'main'. The init script reads the first options, to start uhttpd; the exporter reads the others in each scrape.

    Option Type Default Datatype Description Read by
    enabled boolean 1 — Run the service; 0 stops it. init script
    listen_interface string loopback — The logical interface uhttpd listens on, or * for every address. init script
    listen_port integer 9100 range(1,65535) The port uhttpd listens on. init script
    http_keepalive integer 70 uinteger Seconds an idle connection is kept open; 0 for none. init script
    cert string unset — The certificate to serve HTTPS with, along with key. init script
    key string unset — The private key of cert. init script
    auth_user string unset username The user a scrape logs in as (basic auth), with auth_password; HTTPS only. init script
    memory_limit integer 0 zero_or_min(8) MB of memory each of the exporter's processes may take (its data, RLIMIT_DATA), 8 or more: a collector that takes more fails alone. 0 for a quarter of the RAM, at most 64 MB. init script
    omit_zero_values boolean 0 — Leave out counters that are 0, most of which never move on a router. exporter
    compress boolean 1 — Send a scrape gzip-compressed when the scraper asks for it (Accept-Encoding: gzip); 0 never does. exporter
    exec_timeout integer 5 range(1,30) Seconds the programs a collector runs get in all in each scrape, unless the collector says otherwise; one still running then is killed. exporter
    scrape_timeout integer 10 range(1,60) Seconds a scrape has to answer when the scraper does not say (X-Prometheus-Scrape-Timeout-Seconds); collectors left when they are nearly spent are skipped. exporter
    collector_budget integer 5 range(1,60) Seconds a collector may take in a scrape, unless it says otherwise; one still running then is stopped, and quarantined for a few scrapes. exporter
    max_samples integer 20000 range(1,100000) Samples a collector may write in a scrape, unless it says otherwise; one that writes more fails, and none of its samples are served. exporter
    max_scrape_samples integer 200000 range(1,1000000) Samples the collectors of a scrape may write in all; a collector whose samples would go past it fails, and none of its samples are served. exporter

    Options that go together, checked wherever the configuration is checked (start, reload, check, the ubus object's validate and LuCI):

    • auth_user without auth_password: basic auth needs the hash of a password along with auth_user.
    • auth_user without cert and key: basic auth needs HTTPS: set cert and key, or the password crosses the network in the clear.
    • auth_password without auth_user is no basic auth: the hash stays saved, unused.

    Basic auth's hash¶

    config auth 'main' in /etc/config/prometheus-exporter-auth, which the package installs, mode 0600. It is apart so that LuCI's ACL, which grants reading the exporter's config, never grants the hash: the ubus object's set_password writes it, and password says whether one is saved. The init script reads it, and the jail does not mount it. A change reloads the service, as one of the main section does.

    Option Type Default Datatype Description Read by
    auth_password string unset crypt The crypt hash of the password of auth_user: $1$ (uhttpd -m), $5$ or $6$, as the ubus object's hash_password makes it. init script

    Collector sections¶

    config collector '<module>', one per collector, named after its module: the collector's name with _ for - (ltq_dsl for ltq-dsl), as a uci section name cannot hold -. A collector without a section runs with its defaults. A section that names no installed collector, and one without a name, is ignored (check warns of both). Besides its own options, listed in Collectors, every collector has these:

    Option Title Type Default Datatype Description
    enabled Enabled boolean 1 — Serve this collector; 0 leaves it out, and naming it in a query is a 400.
    timeout Program timeout integer the collector's meta.timeout, else exec_timeout (5) range(1,30) Seconds the programs of this collector get in all in each scrape; one still running then is killed.
    budget Budget integer collector_budget (5), or the collector's timeout and a second more when that is longer range(1,60) Seconds this collector may take in a scrape; one still running then is stopped, and quarantined for a few scrapes.
    max_samples Sample limit integer the collector's meta.max_samples, else max_samples (20000) range(1,100000) Samples this collector may write in a scrape; one that writes more fails, and none of its samples are served.

    timeout is only for a collector that runs programs (exec in its needs); the others ignore it. A collector still running at the end of its budget is stopped and quarantined, and one that writes more than its max_samples fails: see Collector contract and About deadlines and circuit breakers. No collector may declare an option named enabled, timeout, budget, max_samples.

    Values¶

    A boolean takes 1, yes, on, true, enabled for true and 0, no, off, false, disabled for false. An integer is decimal digits, with an optional -. A string is a single value, not a list. A datatype narrows what an option takes, by the name LuCI gives it; the exporter checks it itself:

    Datatype Takes
    crypt a crypt hash: $1$ (uhttpd -m), $5$ or $6$
    file an absolute path
    owned_directory a directory under /var, /tmp or /etc/prometheus-exporter, which the service makes and mounts
    range(1,100000) an integer from 1 to 100000
    range(1,1000000) an integer from 1 to 1000000
    range(1,30) an integer from 1 to 30
    range(1,60) an integer from 1 to 60
    range(1,65535) an integer from 1 to 65535
    regex a regular expression
    uinteger an integer of 0 or more
    username a user of 1 to 64 characters, without ":", spaces or control characters
    zero_or_min(8) 0, or an integer of 8 or more

    directory and file check the path's form, not that it exists. A value an option does not take is CONFIG_INVALID: in the main section it stops start and reload, and in a collector's section that collector fails in each scrape. See Error codes.

    What is wrong with a value¶

    What the exporter finds wrong with a value, or with options that go together, has a code of its own, from src/prometheus_exporter/config/problems.uc, and arguments. The ubus object's validate answers the code and its arguments, for a client to say in its own words, as LuCI does, and the English below as message (see ubus object). The details of a CONFIG_INVALID, in the log, check and the command line, are that English after the option's name: listen_port: expected an integer from 1 to 65535, got 0. value is what the exporter read, but for a secret option's (auth_password).

    Code Arguments English
    BOOLEAN value expected a boolean, got value
    INTEGER value expected an integer, got value
    SINGLE value expected a single value, got value
    RANGE min, max, value expected an integer from min to max, got value
    UINTEGER value expected an integer of 0 or more, got value
    ZERO_OR_MIN min, value expected 0, or an integer of min or more, got value
    ABSOLUTE_PATH value expected an absolute path, got value
    OWNED_DIRECTORY value expected a directory under /var, /tmp or /etc/prometheus-exporter, which the service makes and mounts, got value
    REGEX value expected a regular expression, got value
    USERNAME value expected a user of 1 to 64 characters, without ":", spaces or control characters, got value
    CRYPT value expected a crypt hash: $1$ (uhttpd -m), $5$ or $6$, got value
    CRYPT_ROUNDS max, value expected a hash of at most max rounds, which a scrape computes to check the password (hash_password makes one of 1000; one without rounds= has 5000), got value
    INTERFACE value expected an interface name or *, got value
    AUTH_NEEDS_PASSWORD — basic auth needs the hash of a password along with auth_user
    AUTH_NEEDS_TLS — basic auth needs HTTPS: set cert and key, or the password crosses the network in the clear

    Example¶

    config prometheus-exporter 'main'
    option enabled '1'
    option listen_interface 'loopback'
    option listen_port '9100'
    option http_keepalive '70'
    option memory_limit '0'
    option omit_zero_values '0'
    option compress '1'
    option exec_timeout '5'
    option scrape_timeout '10'
    option collector_budget '5'
    option max_samples '20000'
    option max_scrape_samples '200000'

config collector 'textfile'
    option enabled '1'
    option directory '/var/prometheus'

    With basic auth, auth_user in the main section above, and in /etc/config/prometheus-exporter-auth:

    config auth 'main'
    option auth_password '$6$rounds=1000$...'
