    Collectors¶

    Every collector of ucode-prometheus-exporter 0.2.1. A collector's name is what a scrape's collect[]= takes and the suffix of its package; its section in /etc/config/prometheus-exporter is named after its module, the name with _ for -. Its options are in that section; UCI configuration has the section's rules.

    Packages¶

    The base package, ucode-prometheus-exporter, installs conntrack, cpu, entropy, exporter, filefd, loadavg, meminfo, netclass, netdev, openwrt_interfaces, selinux, softnet, time, timesync, uname, vmstat. Every other collector is a package of its own, ucode-prometheus-exporter-<name>, which depends on the base package of the same release. A group package installs no files, only its collectors.

    Group package For Collectors
    ucode-prometheus-exporter-network network statistics ethtool, nat_traffic, netstat, nft-counters, qdisc, snmp6, sockstat
    ucode-prometheus-exporter-wireless Wi-Fi hostapd_stations, hostapd_ubus_stations, wifi
    ucode-prometheus-exporter-hardware hardware and filesystems diskstats, filesystem, hwmon, thermal
    ucode-prometheus-exporter-full a router or access point ethtool, nat_traffic, netstat, nft-counters, qdisc, snmp6, sockstat, hostapd_stations, hostapd_ubus_stations, wifi, diskstats, filesystem, hwmon, thermal, dhcp_leases, dnsmasq, openwrt, textfile, uci_dhcp_host, wireguard

    In no group: bmx7, chrony, dawn, ltq-dsl, modemmanager, mwan3, realtek-poe, ubnt-manager, unbound.

    Nothing to observe¶

    These collectors can have nothing to observe: they succeed without samples, and their node_scrape_collector_observing is 0. Every other collector fails when it cannot read what it reads. The reasons are what check, the ubus object's status and LuCI's status page show.

    Collector Nothing to observe when Reasons it gives Still a failure
    bmx7 bmx7 disabled, or not installed. bmx7 is disabled, bmx7 is not installed bmx7 enabled, and its status files unreadable.
    chrony chronyd disabled, or not installed. chronyd is disabled, chronyd is not installed chronyd enabled, and chronyc failing (chronyd stopped).
    conntrack nf_conntrack not loaded: none of its files in /proc/sys/net/netfilter. no connection tracking (nf_conntrack is not loaded) Its files there and unreadable.
    dawn DAWN disabled, or not installed. dawn is disabled, dawn is not installed DAWN enabled, and its dawn object missing or failing.
    dhcp_leases dnsmasq (or no dnsmasq instance in /etc/config/dhcp) and odhcpd both disabled or not installed. With one of them enabled, it observes that one. dnsmasq is disabled, dnsmasq is not installed, odhcpd is disabled, odhcpd is not installed An enabled server that is not there: no dnsmasq lease file, odhcpd not on ubus.
    diskstats Every block device in /proc/diskstats is one device_exclude leaves out (by default flash, loop devices, zram and partitions): a router without a disk. Or no block device at all. device_exclude leaves out every block device, no block devices /proc/diskstats not there or unreadable; a line of a device it exports that is malformed.
    dnsmasq dnsmasq disabled, or not installed. dnsmasq is disabled, dnsmasq is not installed dnsmasq enabled, and its dnsmasq object missing or failing.
    hostapd_stations As wifi, or no hostapd.<ifname> object for any interface. no wireless radios, no hostapd access points A hostapd object that does not answer.
    hostapd_ubus_stations No hostapd.* object. no hostapd access points A hostapd object that does not answer.
    ltq-dsl No dsl object. no DSL modem (no dsl on ubus) A dsl object that does not answer.
    modemmanager ModemManager disabled or not installed, or it lists no modem. ModemManager lists no modems, modemmanager is disabled, modemmanager is not installed mmcli failing or running out of time with ModemManager enabled.
    mwan3 mwan3 disabled, or not installed. mwan3 is disabled, mwan3 is not installed Its mwan3 object failing. Enabled and stopped is a reading: mwan3_interface_running 0.
    nat_traffic nf_conntrack not loaded: no /proc/net/nf_conntrack. no connection tracking (nf_conntrack is not loaded) The file there and unreadable.
    realtek-poe No poe object. no PoE switch (no poe on ubus) A poe object that does not answer.
    snmp6 No /proc/net/dev_snmp6 (IPv6 disabled). no IPv6 (no /proc/net/dev_snmp6) The directory there and unreadable.
    timesync Neither busybox ntpd nor chronyd runs, as procd's instances say: sysntpd runs ntpd only while /etc/config/system turns NTP on. With one running, it observes that one. neither ntpd nor chronyd runs chronyd enabled and not running, or chronyc failing; busybox ntpd's event file unreadable.
    ubnt-manager ubnt-manager not installed, or ubnt-manager -l lists no radio. ubnt-manager is not installed, ubnt-manager lists no radios A radio that fails or does not answer.
    unbound unbound disabled, or not installed. unbound is disabled, unbound is not installed unbound enabled, and its control socket not answering.
    wifi No network.wireless object, or one without radios. no wireless radios Another failed call; an interface nl80211 cannot answer for.
    wireguard rpcd has no wireguard object: rpcd-mod-wireguard not installed. rpcd has no wireguard object: rpcd-mod-wireguard is not installed Any other failure of wireguard status.

    bmx7¶

    The bmx7 mesh node, its links and tunnels, from its JSON status files.

    • Title: bmx7 mesh
    • Package: ucode-prometheus-exporter-bmx7
    • Section: config collector 'bmx7'
    • Needs: fs, ubus
    • Jail paths: /var/run/bmx7/json
    • Nothing to observe: bmx7 disabled, or not installed. See Nothing to observe.
    • Metrics: bmx7
    Option Title Type Default Datatype Description
    enabled Enabled boolean 1 — Serve this collector; 0 leaves it out, and naming it in a query is a 400.

    chrony¶

    chronyd's tracking and sources, and its server statistics where it serves time, from chronyc.

    • Title: chrony NTP daemon
    • Package: ucode-prometheus-exporter-chrony
    • Section: config collector 'chrony'
    • Needs: ubus, uci, fs, exec
    • Reads the configs: /etc/config/chrony
    • Runs: chronyc (only where it is installed), with /bin/sh
    • Seconds for its programs: The main section's exec_timeout, unless its section sets timeout
    • Nothing to observe: chronyd disabled, or not installed. See Nothing to observe.
    • Metrics: chrony
    Option Title Type Default Datatype Description
    enabled Enabled boolean 1 — Serve this collector; 0 leaves it out, and naming it in a query is a 400.
    timeout Program timeout integer exec_timeout's (5) range(1,30) Seconds the programs of this collector get in all in each scrape; one still running then is killed.

    dhcp_leases¶

    Active DHCP leases of dnsmasq and odhcpd, by interface and family.

    • Title: DHCP leases
    • Package: ucode-prometheus-exporter-dhcp_leases
    • In the groups: ucode-prometheus-exporter-full
    • Section: config collector 'dhcp_leases'
    • Needs: fs, ubus, uci, time
    • Reads the configs: /etc/config/dhcp
    • Jail paths: The lease file of each dnsmasq section of /etc/config/dhcp: its leasefile, or /tmp/dhcp.leases.
    • Nothing to observe: dnsmasq (or no dnsmasq instance in /etc/config/dhcp) and odhcpd both disabled or not installed. With one of them enabled, it observes that one. See Nothing to observe.
    • Metrics: dhcp_leases
    Option Title Type Default Datatype Description
    leases Lease series boolean 0 — A series per lease, with its address, MAC, hostname and expiry.
    enabled Enabled boolean 1 — Serve this collector; 0 leaves it out, and naming it in a query is a 400.

    diskstats¶

    Reads, writes, discards and flushes of each disk, and the time spent on them, from /proc/diskstats, as node_exporter has them.

    • Title: Disk I/O
    • Package: ucode-prometheus-exporter-diskstats
    • In the groups: ucode-prometheus-exporter-hardware, ucode-prometheus-exporter-full
    • Section: config collector 'diskstats'
    • Needs: fs
    • Nothing to observe: Every block device in /proc/diskstats is one device_exclude leaves out (by default flash, loop devices, zram and partitions): a router without a disk. Or no block device at all. See Nothing to observe.
    • Metrics: diskstats
    Option Title Type Default Datatype Description
    device_exclude Excluded devices string ^(z?ram|loop|fd|(h|s|v|xv)d[a-z]|nvme[0-9]+n[0-9]+p|mtdblock|ubiblock[0-9]+_|mmcblk[0-9]+(p|boot))[0-9]+$ regex A regular expression of the block devices to leave out: by default RAM disks, zram, loop devices, flash (mtdblock, ubiblock) and the partitions of disks, whose I/O their disk counts. ^$ leaves out none.
    enabled Enabled boolean 1 — Serve this collector; 0 leaves it out, and naming it in a query is a 400.
